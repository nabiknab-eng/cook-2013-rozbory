# Cookova studie 2013 — dva české rozbory

Statický web: https://nabiknab-eng.github.io/cook-2013-rozbory/

- [Stručný rozbor](https://nabiknab-eng.github.io/cook-2013-rozbory/strucny-rozbor.html)
- [Podrobný rozbor](https://nabiknab-eng.github.io/cook-2013-rozbory/podrobny-rozbor.html)

HTML stránky jsou statické, bez externích knihoven, fontů a analytiky. Zdrojové Markdown soubory jsou uloženy vedle HTML.

Rozbory třídí obsah a stanoviska; samostatně nereprodukují klimatické výpočty. Počet vlastních atribučních prací ve všech 11 944 položkách nebyl určen.
